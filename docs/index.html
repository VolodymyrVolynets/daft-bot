Sign in with a GitHub token

The bot runs in GitHub Actions; this page changes it through the GitHub API. You need a token that can only access this one repository:

  1. Open GitHub → New fine-grained token.
  2. Name: daft-bot admin. Expiration: as long as you like.
  3. Repository access: Only select repositories → .
  4. Permissions → Repository: Actions: Read and write and Contents: Read and write.
  5. Generate, copy and paste it here. It's stored only in this browser.
